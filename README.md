# 实验二：人脸表情情感分类（7 类）

基于 MobileNetV2 迁移学习的人脸表情识别模型，前置人脸检测与关键点对齐，针对 FER2013 的严重类别不均衡引入类别加权与标签平滑。对应《深度学习图像分析实验报告》第 3 章。

## 一、任务定义

七类表情：愤怒、厌恶、恐惧、开心、悲伤、惊讶、中性。

```
输入 → 人脸检测裁剪 → 五点/双眼对齐 → 224×224×3 → MobileNetV2 → 7 类
```

## 二、模型结构

```
输入 224×224×3
   └─ MobileNetV2（ImageNet 预训练，替换原分类层）→ 1280 维特征
        └─ Dropout(0.2) → Linear(1280→7)
```

损失函数（带类别权重与标签平滑）：

```
L = -1/N * Σ_i Σ_c  w_c * y_{i,c} * log p_{i,c}      y 为平滑后标签，ε = 0.1
```

## 三、安装

```bash
pip install -r requirements.txt
```

可选安装 MTCNN（精度更好，但依赖 torch）：

```bash
pip install facenet-pytorch
```

未安装时 `face_align.py` 自动回退到 OpenCV Haar 级联检测，并用双眼位置做旋转校正。

## 四、数据准备

数据不入库，只放划分清单。`data/train.csv`、`data/val.csv`、`data/test.csv`，每行：

```csv
image_path,label
images/fer0001.jpg,angry
images/fer0002.jpg,happy
```

类别顺序在 `configs/labels.json` 中维护。仓库内附 `data/train_sample.csv` 作为格式示例。

划分要求：训练 70%、验证 20%、测试 10%，**按人物分组**，同一人的多张图不得跨集合。

FER2013 类别分布极不均衡（厌恶类仅约 1.4%），训练脚本默认按频次倒数自动加权，不需手工调。

## 五、训练

```bash
python train.py --train_csv data/train.csv --val_csv data/val.csv \
       --epochs_stage1 8 --epochs_stage2 32 --batch_size 64
```

两阶段迁移：

1. 阶段一：冻结主干，只训分类头，lr = 3e-4，8 轮；
2. 阶段二：解冻全部参数，lr = 1e-5，32 轮，余弦退火；
3. 以验证集**宏平均 F1**（而非准确率）选模型并早停，避免多数类主导。

## 八、注意事项

- 增强禁区：不做垂直翻转（上下颠倒的人脸不属于自然分布）、不做强色相变换（肤色是辅助线索）、不做大幅随机擦除（小样本下等于信息丢失）。
- 瓶颈：恐惧与惊讶在 48×48 分辨率下形变差异被抹平，提升分辨率为主要改进方向。
- 可选改进：把眼部、口部裁剪出的子图作为第二路输入做双流融合，模型接口已预留 `model.py` 的 `TwoStreamEmotion`。
